# OPEN CIRCUIT

A student developer portfolio. Built with Vite, semantic HTML, and Tailwind CSS.

## Run locally

1. Open this folder in a terminal.
2. Install packages once: `npm install`
3. Start the site: `npm run dev`
4. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Edit your content

Most of the website lives in `index.html`.

- Hero text is near `id="hero"`
- Project slots are in the Work section (`id="work"`)
- About text is in the About section (`id="about"`)
- Email, GitHub, and LinkedIn are in the Contact section (`id="contact"`)
